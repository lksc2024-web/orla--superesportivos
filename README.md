# Orla Superesportivos

Projeto demonstrativo: site de uma loja fictícia de superesportivos com um Lamborghini Aventador em 3D (three.js).

- Estúdio escuro com as luzes acendendo na abertura e piso espelhado
- Câmera guiada pelo scroll em cinco capítulos: destaque, estoque, configurador, oficina e test drive
- Configurador ao vivo de pintura, rodas e pinças de freio
- Site estático: `index.html` + `car.glb`, sem build

Loja, estoque e contatos são fictícios. Modelo 3D do projeto [automotive-configurator](https://github.com/codeagencybe/automotive-configurator), originalmente de tf3dm.com, comprimido em Draco e com emblemas removidos. Lamborghini e Aventador são marcas da Automobili Lamborghini S.p.A.; este projeto não tem ligação com a marca.
