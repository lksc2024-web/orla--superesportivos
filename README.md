# FM Arquitetura e Interiores: prévia conceitual

Prévia comercial não oficial, sujeita à aprovação da FM Arquitetura e Interiores.

- Next.js 15 (export estático), TypeScript, Tailwind CSS 4, three.js
- `npm run build`, `npm run lint`, `npm run typecheck`
- Imagens: estudos 3D (Blender/Cycles, `tools/`) e imagens ilustrativas de ambientes fornecidas pelo cliente, ampliadas com EDSR (OpenCV) e com profundidade estimada por MiDaS. Nenhuma é obra real da FM.
- Mobiliário 3D: Khronos glTF Sample Assets (Wayfair CC BY 4.0 / CC0; Darmstadt Graphics Group CC BY 4.0).
